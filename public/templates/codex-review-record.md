# Codex 审查记录表

来源：Codex Study Club
使用说明：https://codex.modelsp.com/cases/reusable-review-skill
模板版本：2026-10-21

这是空白记录表，不会安装 Skill，不是自动检测工具，也不保证消除误报和漏报。
用文本编辑器填写；另存新记录，不覆盖已有结果。分享前移除私有数据和密钥。

## 审查边界

- 时间与时区：[填写]
- 任务与预期行为：[填写需求或规则来源]
- 待审查范围：[PR、提交或文件；含排除项]
- 版本：[提交 SHA；有未提交改动时另附差异或文件快照]
- 原有改动与归属：[已暂存、未暂存、未跟踪；不因审查清理现场]
- 客户端与可确认的配置：[版本、模型等；未知写不可得]
- 使用的规则或 Skill：[名称、文件版本，以及实际读取证据]
- 调用方式：[技能显式选择 / 隐式选择 / 直接读取文件 / 未确认]
- 可用验证与限制：[命令、页面、日志；缺失条件如实填写]

## 发现或疑点（按需复制，不为填表制造发现）

- 状态：[确认发现 / 待核实 / 已驳回]
- 标题与影响：[具体影响；严重程度以实际影响解释]
- 对应版本与文件位置：[可复核文件、行号或段落]
- 触发条件：[输入、操作、环境或前提]
- 预期行为与依据：[填写]
- 实际行为或内容：[填写]
- 证据类型：[静态阅读 / 实际运行 / 外部作者报告]
- 证据位置与结果：[命令及退出码、可定位输出、正文或页面]
- 未验证面与缺少的条件：[填写；不要把推断写成复现]
- 处理决定：[接受 / 暂缓 / 驳回；说明理由]

## 验证记录

- 检查对象与版本：[填写；版本变化需重新确认适用性]
- 静态检查：[读过的路径或依据；没有则说明]
- 实际执行：[命令/操作、结果；未执行不填通过]
- 动态交互（适用时）：[本次需求相关的连续操作、失败、取消、保存等状态]
- 未执行或失败：[原因、下一步与预期证据]
- 修改后复核：[新版本、检查、实际结果；未修改则不适用]

## 审查结论

- 确认发现：[列出记录引用；无则写本次范围内没有确认发现]
- 待核实项：[列出；无则写无]
- 已检查范围与残余风险：[明确未覆盖部分]
- 报告状态：[待核验 / 已核验本次范围]
- 后续操作：[只读报告 / 另有明确要求的修复或发布；不要由报告推断已发布]

## 复核报告的提示词

请只读复核这份报告与对应版本。逐条核对范围、位置、触发条件、预期与实际、证据。
将没有依据的结论移到待核实，说明缺少的材料；不要为了填满表格生成发现。
区分静态阅读、实际执行、外部作者报告和未验证项。
有界面行为时，检查已有证据覆盖了哪些真实操作，不用静态测试替代交互验收。
最后列出确认发现、待核实项与残余风险，不改代码或发布评论。
