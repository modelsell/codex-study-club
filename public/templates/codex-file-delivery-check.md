- 检查日期、时区：
- 使用入口、客户端版本、操作系统：
- 预期文件名、格式和关键内容：
- 执行环境：本机 / 远程主机 / 云端 / 未知
- 文件相对路径或脱敏位置：
- 来源页面、链接文字、公开目标地址（移除令牌和私人信息）：

HTTP 200 不证明拿到正确文件；非空不证明格式有效；直接打开正常不证明客户端链接可用。没有操作的项目保留“未验证”。

公开分享前移除本机绝对路径、账号、访问令牌、私人文件内容和原始访问日志。只保留诊断所需的相对路径与脱敏信息。
