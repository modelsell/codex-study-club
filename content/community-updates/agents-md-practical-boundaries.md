# AGENTS.md 应该写什么：来自五个项目的边界整理

> 整理说明：本文来自付费社群中的真实讨论。成员身份、项目名称和敏感信息均已移除。

## 本期观察

团队往往会把所有要求都放进 AGENTS.md，最后让长期规则和临时任务互相冲突。

- 稳定的项目命令、目录边界和验证要求适合长期保留。
- 只对当前任务有效的要求应该放在任务描述中。
- 规则之间出现冲突，比规则缺失更容易造成执行不稳定。

## 可以带走的结论

> 把 AGENTS.md 当成给 coding agent 的项目工作手册，而不是无限增长的提示词仓库。

## 继续实践

检查当前项目的 AGENTS.md，删除临时任务要求，并确认每一条长期规则都能在实际工作流中执行和验证。
