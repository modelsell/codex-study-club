# 9 月新玩法：透明贴纸、随手聊天与灵感扭蛋

这期不列长长的更新清单，挑几个能变成小作品的点。下面区分官方已公布的变化与本站设计的练习；核对日期为 2026-09-29，练习效果不代表已经替你实测。

## 昨天的新变化：让图像更像能拿来用的素材

[官方更新日志](https://learn.chatgpt.com/docs/changelog)的 2026-09-28 条目列出 CLI **0.158.0**：图像生成与编辑可以明确请求透明背景，编辑也支持来自文件的对话图片。终端方面，选中复制、右键粘贴可以配置，复制对话选区会保留 Markdown 格式。这里的发布日期是 09-28，本文整理日期是 09-29。

### 可以试：给你的小项目做一枚透明贴纸

在你的客户端已经提供图像工具时，拿自己创作或有权使用的素材尝试：

```text
给我的像素猫小项目设计一枚原创贴纸：戴薄荷色围巾的圆脸小猫，
只有角色，没有文字、底板或投影背景。需要真正透明的背景。
如果能生成文件，请交付支持透明通道的格式；
如果当前工具不支持透明输出，直接说明，不用棋盘格图案冒充透明。
```

验收时把图片分别放在深色和浅色背景上，看四角是否透出底色、边缘是否有白框。导出了一张图片，不等于已经得到透明素材；照片里画着棋盘格也不是透明通道。

这是一道建议练习，本轮没有生成贴纸。功能范围、工具访问与用量以你当前账号和环境为准，也不需要为读这篇文章先升级套餐。

## 本月值得回看：桌面宠物也能接住一个小念头

官方 09-11 更新介绍了从 Pets 浮动控件发送 Quick Chat。它适合随手问一句；需要项目上下文时，仍应回到主应用里的对应项目。完整入口和练习见[桌面宠物玩法](/cases/17-desktop-pet)。

可以先让它为一段自己写的介绍想三个标题，再选一个继续改。第一步拿到的是候选标题，不是已经替你发到网站。

## 今天就能玩：抽一颗灵感

本站上线了[灵感扭蛋机](/play)，提供六个原创小项目挑战：

- 宇宙番茄钟：让小星球陪你专注。
- 网页像素猫：给摸摸、喂食和休息配上不同回应。
- 午饭抽签盒：从自己的候选列表抽一个结果。
- 心情明信片：把三行短句排成可打印的小卡片。
- 三扇门推理：把一条逻辑规则变成可以点的谜题。
- 今日成就勋章：给修掉的小 Bug 发一枚奖励。

抽签和复制在网页本地完成，无需登录本站或提供 API Key。提示词只是起点；去自己的练习目录执行后，按卡片里的清单检查。先完成一个按钮、一个状态或一张卡片，再加第二个愿望。
