# Codex CLI 0.160.0：把旧任务、终端文本和工作区边界接起来

OpenAI 官方更新日志将 **Codex CLI 0.160.0** 标为 2026-10-01 发布。本站于 2026-10-03 对照原文整理；下面的命令与练习是可复现的准备步骤，不代表本站已经在你的机器上完成升级或验证。

## 这次更新改变了什么

官方列出四项变化，其中前三项更容易立刻变成日常工作流：

- Agent command center 可以用键盘访问 **Show more**，继续浏览更早的任务。
- 在支持的本地 **Linux X11** 终端全屏模式中，可以选择 transcript 文本并用鼠标中键粘贴。
- 在策略允许时，可以在项目外启动会话，使用工作区默认值；恢复会话时会还原已保存的权限。
- Guardian review 能够选择性地取回更早的用户指令，并带入 agent handoff 的上下文。这是可选能力，不应被当作所有环境都默认开启。

这不是“所有终端都获得中键粘贴”。官方限定了本地 Linux X11 和全屏模式；macOS、Windows、远程终端或不支持中键的环境需要沿用原有复制粘贴方式。

## 先确认版本和环境

不要为了验证新闻直接改动正在使用的全局 CLI。可以在隔离环境或已经有版本管理的机器上先查看：

```bash
codex --version
```

如果你决定升级，再按项目的版本策略执行官方给出的安装命令：

```bash
npm install -g @openai/codex@0.160.0
```

安装后再次运行 `codex --version`，把实际输出与预期版本记录在自己的变更或复盘里。本站没有在本轮执行全局安装，也没有把版本字符串写成实测结果。

## 一个 10 分钟的小练习：找回昨天的任务

这个练习的目标是确认“历史任务更容易找”和“恢复权限”是否适合你的工作方式，不需要联网写入仓库：

1. 启动 CLI，打开 agent command center，使用键盘移动到 **Show more**，记下能看到的最早一条任务标题。
2. 选一个没有敏感信息、可以丢弃的旧任务，先只读查看它的工作区和权限提示，不继续执行原任务。
3. 如果你在支持的 Linux X11 全屏终端，选择一小段 transcript 文本并用中键粘贴到临时文本框；其他环境用键盘复制粘贴完成同一检查。
4. 启动一个项目外的临时会话，确认它使用的工作区默认值；恢复刚才的旧会话，检查权限提示是否与预期一致。
5. 关闭临时会话，删除临时文本，不提交、不推送任何文件。

### 验收清单

- [ ] 能用键盘触达并展开更早任务；看不到该入口时记录客户端、登录方式和版本。
- [ ] 文本粘贴方式与终端环境匹配；不把 Linux X11 的行为外推到其他系统。
- [ ] 项目外会话没有意外继承不该带入的项目文件或权限。
- [ ] 恢复会话后，实际显示的权限与自己的预期一致；不根据“恢复成功”推断所有工具都可用。
- [ ] 全程没有执行旧任务的写入、提交或部署动作。
