01 / EXECUTIVE SUMMARY

先读这六条，就读懂了整场交流

表面上讨论的是开源、定价、算力与产品，底层反复出现的却是同一个问题：怎样让团队以最小阻力、最长时间、最高概率推进 AGI。

01

“克制”是一种战略

少拿短期利润、少抢应用入口、少树敌，换来人才凝聚、生态支持和更大的长期选择权。它不是放弃商业，而是改变商业利益的时间分布。

02

开源与赚钱并不冲突

前提是服务成本足够低、利润要求足够克制。真正的壁垒不是“别人拿不到模型”，而是别人难以用同样的成本、速度和体验把模型服务好。

03

产品是研究的副产物

C 端用户和 B 端 API 都被视为 AGI 路上的阶段性产出，而不是反过来牵引研究方向。当前最稀缺的资源应继续投向模型能力，而非完整商业闭环。

04

下一个瓶颈是持续学习

从语言模型、思维链到 Agent，每一步都扩展了能力边界；但模型仍缺少像员工一样长期吸收组织上下文的能力。持续学习被视为通往自我迭代的关键台阶。

05

真正的核心资产是团队

模型会迭代、产品会过时、资本与算力可以买到；最难替代的是已经形成协作方式与共同愿景的研究团队，因此团队稳定被定义为首要核心利益。

06

中国的结构性机会在效率

算力供给是短板，成本工程、编译栈和产品体验可能是优势。CUDA 生态壁垒有机会被高级编译语言与 AI 编程削弱，但芯片产能仍是更硬的约束。

02 / THE CORE LOGIC

“克制”如何转化为竞争力

整场交流最值得关注的不是某个单点判断，而是这条闭环逻辑。它把价值观、组织机制和商业策略连在了一起。

愿景驱动目标不是利润最大化，而是把对人类有用的 AI 做成。
主动克制不追求垄断租金，不把每一个产品与流量机会都收入囊中。
开源 + 低成本让模型可获得、可部署、可负担，降低社会采用门槛。
人才与生态更容易聚合研究者、伙伴和用户，减少外部对抗。
提高成功概率团队更稳定、资源更聚焦、研究节奏更持久。
关键变化：竞争对象从“市场份额”变成“成功概率”。

当终局足够大时，争取更高的成功概率，比在早期多拿几个百分点的收入更有价值。这是他所有反常规选择的共同解释。

03 / AGI ROADMAP

他所描述的技术阶梯

这是一条“前一步帮助完成后一步”的省力路线。越往后，AI 越多地参与自身研发，进步因此可能呈现非线性。

01
语言模型在完整上下文内形成通用能力底座
02
思维链通过推理提高任务能力上限
03
Agent把推理扩展到多步骤行动与工具使用
04
持续学习长期吸收环境、组织与任务上下文
05
自我迭代AI 参与开发下一代 AI，研究加速
06
具身智能进入物理世界，替代具体的人力需求

边界：文字稿明确把这称为 DeepSeek 自己的判断，而非唯一技术路线；持续学习目前仍没有被证明有效的完整方案。

04 / STRATEGIC CHOICES

什么优先，什么顺手做，什么暂不做

这套资源配置方式非常清晰：主线由“是否提高智能上限”决定，产品价值与商业价值不能自动获得最高优先级。

主线：集中投入

直接推动通用智能能力与研究效率。

  • 训练与后训练
  • 持续学习
  • 通用 Agent / Coding Agent
  • 模型效率与低成本架构
  • AI 辅助 AI 研发

组件：必须具备

对产品重要，但不是智能主线本身。

  • 原生多模态
  • 搜索与工具调用
  • 幻觉治理
  • C 端体验
  • B 端 API 服务

暂不优先

商业上可能成立，但当前不提高智能上限。

  • 视频生成
  • 3D 生成
  • 垂直行业 Agent
  • 广告、电商、本地生活闭环
  • 上游芯片垂直整合

八个核心观点

01 / 愿景

愿景不是口号，而是公司实际如何取舍

组织不依赖密集 KPI 与规则，而依赖成员对“大方向”的共同理解。愿景的真实性要由降价、开源和不争抢应用等具体行为证明。

来源：第 2-6 页，00:00:01 起
02 / 开源

开源是价值观，也是商业策略

AI 市场足够大，独占并不现实。模型开放后，部署效率、服务成本与用户体验仍构成壁垒；开源还会扩大采用和生态协作。

来源：第 3-9 页，00:11:49-00:50:00
03 / 商业

合理利润，而非利润最大化

定价围绕设备回收与可持续经营，而非需求无弹性时的最高可收价格。C 端与 B 端都要做好，但不应反向吞噬 AGI 研究资源。

来源：第 4-8、18-19、38-40 页
04 / 组织

团队稳定是唯一不可退让的核心利益

正式项目与自由探索并行，理想状态下集中任务不超过研究者一半时间。随着规模扩大，部分部门也必须引入更清晰的层级。

来源：第 13-14、25-26、33-34 页
05 / 技术

持续学习比“再做一个 Agent”更接近下一次跃迁

当前模型在给定完整上下文时已很强，但不能像员工一样通过数月工作持续获得隐性背景。解决这一点，才可能真正替代更广泛的人类工作。

来源：第 9-12、31-36 页
06 / 算力

资源差距是中美 AI 差距的主要来源

人才差距很大程度上也是实验机会差距的结果。在算力规模受限时，策略是以架构、算法与工程效率换时间，并在重点方向寻求局部超越。

来源：第 16-18、30-34 页
07 / 芯片

生态壁垒可能下降，产能瓶颈更难

高级编译语言、算子重写和 AI 编程降低了对 CUDA 生态的依赖；但即便软件栈被重建，硬件代际与实际供给仍决定可用算力。

来源：第 20-24、40-41 页
08 / 行业终局

基础模型会收敛，差异集中在成本、时间与体验

当能力趋同，领先多久、服务多便宜、产品多好用成为决定性变量。中国基础模型公司数量会减少，更多价值由应用与行业伙伴共同创造。

来源：第 17-20、28-30、36-39 页

06 / INDEPENDENT ANALYSIS

五个更深一层的洞察

以下是基于全文的分析，不是梁文锋原话。它们解释这套策略真正押注的变量，以及可能被忽视的代价。

这是一种“低抽成的基础设施”战略

通过主动压低利润诉求，DeepSeek 试图成为更难被生态排斥的底层能力提供者。越多伙伴依赖其模型，越能把研究优势转化为事实标准；它追求的不是控制全部价值链，而是在足够大的价值链里占据不可绕过的一层。

生态位判断

开源真正释放的是组织杠杆

开源不只是获客。它让外部开发者承担适配、验证、传播与场景探索，从而使一个保持精简的研究组织获得远超自身人数的覆盖面。换句话说，克制与聚焦之所以可行，是因为生态在补齐公司没有做的部分。

组织效率

“先让自己好用”是最短反馈回路

把下一代模型首先用于 DeepSeek 自己的研发，意味着真实用户、任务定义者和模型研发者在同一组织内，反馈周期极短。如果这一内循环成立，AI 提升研究效率，研究再提升 AI，增长将从模型能力竞争变成研究吞吐量竞争。

递归加速

最大护城河也是最大单点风险

当公司把团队稳定定义为最重要资产，组织文化便同时成为优势与脆弱点。共识驱动在小规模研究团队中高效，但扩张后必须引入层级；如何制度化文化而不削弱自由探索，是比单次模型发布更难的长期课题。

治理风险

商业克制本质上是延迟兑现选择权

不急于做广告、电商和垂直应用，保留了未来技术形态变化后的重新选择空间。但它也可能让渡用户关系、专有数据与工作流入口。只有基础模型进步的价值持续大于这些反馈资产，克制才始终是最优策略。

07 / TENSIONS TO WATCH

战略成立，需要跨过这些矛盾

一套逻辑自洽的战略并不等于已经被验证。真正决定结果的，是下列张力能否长期保持平衡。

一端另一端需要观察
开源与低价↔持续高额算力投入

服务效率的领先幅度，能否长期覆盖研究和集群资本开支。

无 KPI、自由探索↔规模化交付与组织层级

新增管理机制是否保持研究者自主性，而不形成协调瓶颈。

聚焦基础模型↔应用侧数据与入口

外部伙伴能否提供足够强的场景反馈，避免模型研发与真实需求脱节。

持续学习的技术信念↔尚无成熟解法

是否出现可复现的长期记忆、稳定更新与避免灾难性遗忘的突破。

软件生态可重建↔芯片供给仍受约束

国产算力的集群可靠性、能效和实际交付速度，而非只看单点 benchmark。

08 / LEADING INDICATORS

比收入更值得跟踪的六个指标

如果把这场交流当作一份战略承诺，后续验证不应只盯 ARR，而应观察承诺是否转化成可重复的组织与技术结果。

01 / 人才

核心团队留存与新人成长

老成员是否稳定，新研究者能否快速进入高自主、高协作的工作方式。

02 / 研究

模型迭代节奏与真实增益

版本是否持续改进成本、速度与能力，而非仅靠更大规模换取分数。

03 / 飞轮

AI 对内部研发的贡献

模型是否真正缩短代码、实验、数据生产和下一代模型开发周期。

04 / 突破

持续学习的可验证进展

是否出现跨时间、跨任务积累经验，同时保持稳定性与可控性的系统。

05 / 效率

单位能力的服务成本

开源模型、官方 API 与第三方部署之间的真实成本差距是否持续存在。

06 / 生态

伙伴而非自营应用的繁荣度

是否有更多高价值产品建立在其模型上，并形成反馈、收入与标准化循环。
