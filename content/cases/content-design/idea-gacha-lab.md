# 抽一个小项目：灵感扭蛋机的七种打开方式

有时候卡住的不是代码，而是“不知道今天做什么”。这次把起点缩小：一个文件、一个小作品、一份验收清单。

**[打开灵感扭蛋机 →](/play)**

## 怎么玩

1. 先看默认的宇宙番茄钟，或点“换一颗灵感”。相邻两次不会抽到同一题；也可以直接点下方七张题签。
2. 阅读提示词中的作品要求与验收清单，点“复制挑战提示词”。如果浏览器不允许自动复制，可以手动复制文本框中的内容。
3. 在 Codex 中选择一个自己的空练习目录，粘贴提示词。先核对目录，再允许创建 `index.html`。
4. 打开生成的文件，按清单逐项操作。没有成功的地方继续修一处，不急着添加一堆功能。

网站上的抽题和复制不调用模型，也不收集你的作品。真正生成项目要在你自己的 Codex 环境里进行；具体用量遵循该环境的规则。时间仅用于安排练习，不能保证一次生成就完成。

## 七颗扭蛋，七种练习

| 挑战 | 有趣的部分 | 顺便练到什么 |
| --- | --- | --- |
| 宇宙番茄钟 | 让小星球陪你专注 | 计时器暂停、重置与重复启动 |
| 网页像素猫 | 摸摸、喂食、休息都有回应 | 状态与文案保持一致 |
| 午饭抽签盒 | 终于不用再问“吃什么” | 空输入、重复项与单个候选 |
| 心情明信片 | 三行短句变成可打印卡片 | 实时预览、纯文本与打印样式 |
| 三扇门推理 | 点一次门，看到完整逻辑解释 | 固定规则与唯一答案 |
| 今日成就勋章 | 小进步也有仪式感 | 表单状态与复制失败处理 |
| 鹈鹕骑摩托车 | 用一个小画面观察 Codex 是否在绕路 | SVG 动画、窄屏布局与重复工具识别 |

## 先玩一局：三扇门推理

**[不用安装，直接试玩 →](/play#tiny-mystery)**

钥匙藏在 A、B、C 三扇门中的一扇，三条线索**恰好一条为真**：A 写“钥匙在 B 门”，B 写“钥匙不在 B 门”，C 写“钥匙不在 A 门”。先选门，再看解释；“重新开始”会清除选择和答案表，并把键盘焦点送回 A 门。

这不是经典的蒙提霍尔换门概率题：没有主持人开门，也没有随机中奖。它练习的是固定规则、唯一解和可解释反馈。

### 怎样验收，而不是只看“答对了”

| 假设钥匙位置 | A 线索 | B 线索 | C 线索 | 真线索数 |
| --- | --- | --- | --- | --- |
| A | 假 | 真 | 假 | 1 |
| B | 真 | 假 | 真 | 2 |
| C | 假 | 真 | 真 | 2 |

A、B 线索互为否定，必有一真。为了只有一条真话，C 必须是假话，于是钥匙只能在 A。选 B 或 C 应明确提示不符合规则；不应该悄悄更换答案。逐个检查三扇门，再用 Tab、Enter 和空格操作，最后重置确认选择和解释都消失。手机窄屏要能读完线索及整张表。

### 复制题目，做自己的版本

回到[扭蛋题库](/play)，选择“三扇门的迷你推理游戏”，复制完整提示词。它要求在自己的空目录生成单文件 `index.html`；本站试玩则集成在现有 React 网站中，两种交付结构不同，规则相同。

第一版通过后，可以复制下面的改编要求：

```text
只更换三扇门的故事背景和门名，不改变三条线索的逻辑关系。
先列出所有候选位置的真值表，确认仍然恰好一个解。
保留错误选择解释、键盘操作和重置功能，不增加联网生成或随机答案。
若改写后的线索无解或多解，先指出问题，不用界面上的“成功”掩盖它。
```

这可以作为[质量回归排查](/community/updates/codex-quality-regression-playbook)中的固定小任务：记录是否唯一解、是否解释错误选择、是否正确重置。单个谜题通过不代表模型整体质量改善。

## 加一点自己的味道

第一版验收通过后，每次只加一个变化。例如：

```text
在现有网页像素猫中，只增加一个“打招呼”动作和三句轮换台词。
保留原来的摸摸、喂食和休息，不新增依赖或网络请求。
先说明需要修改哪几处，再完成并复查四个动作。
```

也可以把午饭抽签改成周末活动抽签，或把明信片改成读书摘录卡。题目可以变，检查空输入、边界和失败状态的习惯继续保留。
