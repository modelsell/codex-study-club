# 把模糊想法变成可验证的第一个任务

## 可以直接使用的任务描述

```text
请为当前文件夹创建一个个人记账页。先查看现有文件，再完成实现。
页面要能新增和删除账目，并显示本月支出总额。
完成后运行可用的检查，并告诉我如何预览。
```

## 关键过程

1. 先让 Codex 阅读工作目录并说明准备修改什么。
2. 把功能范围限制为新增、删除和月度汇总。
3. 要求完成后启动页面并进行实际预览。

## 如何判断完成

- 页面可以正常打开。
- 新增和删除后总额正确更新。
- 刷新后数据仍然保留。

## 验证结果

任务完成后可以直接预览页面，并通过新增、删除和刷新操作检查结果。
