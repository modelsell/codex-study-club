# Codex 账号、套餐与可用范围

::: tip 核对范围
官方资料最后核对日期：2026-09-26。本文只整理官方访问与计费说明，没有执行购买、充值或账号注册测试。具体价格、可用功能与额度以账号页面和官方文档为准。
:::

## 学习前不必先假定要买套餐

当前[官方套餐页](https://learn.chatgpt.com/docs/pricing)列出了 Free、Go 的有限桌面 Codex 访问，并注明受逐步开放影响。因此，“所有 Codex 功能都必须先买 Plus”不是准确的入门前提。能否使用某个入口、模型或功能，需要分别核对。

先用现有账号完成[桌面安装与首次验证](/start/02-app-installation)。如果任务可以执行，再判断真实需求是更高用量、其他入口，还是某项特定功能。

## 核对这四件事

1. **入口**：你需要的是桌面、CLI、IDE 还是云端？一个入口能用，不代表其他入口都有同样权限。
2. **功能**：在[功能可用性表](https://learn.chatgpt.com/docs/pricing#feature-availability)查找你真正要用的功能。
3. **用量**：查看当前账号显示的剩余额度与重置时间，不用他人的“能用多少天”估计替代自己的读数。
4. **工作区**：团队账号还应核对组织设置；遇到访问限制时先确认管理员要求。

## ChatGPT 登录和 API Key 分开理解

[官方快速开始](https://learn.chatgpt.com/docs/quickstart)提供 ChatGPT 账号登录，也说明 Codex 可使用 API Key，但部分功能可能不可用。API Key 的使用按相应 API 规则计费，不应理解为自动包含在已购买的 ChatGPT 订阅中。依据：[官方套餐说明](https://learn.chatgpt.com/docs/pricing)。

如果你只是学习如何读项目、修改一个文件和检查结果，可以先走现有账号路径，不需要为了阅读本教程就创建付费 API 项目。

## 确实需要升级时

从自己的账号进入官方套餐页面，核对所需功能、实际付款金额、续费与取消说明，再决定是否购买。本文不提供第三方接码、代充或跨区礼品卡操作流程，也不把特定套餐描述为适合所有人的最佳选择。

升级后分别检查账号的套餐状态、目标功能是否出现，以及实际任务是否能够完成；付款成功本身不是所有入口均可用的证明。出现不一致时，保留脱敏后的错误信息，通过官方支持或工作区管理员处理。
