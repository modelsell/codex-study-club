# 用手机跟进 Codex：配对主机与验收任务

::: tip 最后核对
官方资料最后核对日期：2026-09-29。配对与连接条件依据 [Remote connections](https://learn.chatgpt.com/docs/remote-connections)。本页是文档核对与练习设计，本轮没有实测手机配对。
:::

## 先确认入口与主机

官方当前将手机入口称为 **Remote**：iOS 或 Android 上的 ChatGPT 连接运行桌面应用的 Mac 或 Windows 主机。功能可能分批开放；两端更新到最新版，并使用同一账号、同一工作区。主机需要保持唤醒、联网和应用运行，工作区也可能要求管理员开启远程访问。

手机发送指令，任务使用主机上的项目、文件、工具与权限。关闭主机应用或让电脑休眠，会中断远程访问；不能因为手机还能打开聊天，就认定后台任务仍在执行。

## 配对一次，再做只读检查

1. 在主机桌面应用打开 **Settings → Connections → Control this Mac or PC**，选择 **Set up** 或 **Add**，完成访问授权与要求的验证。
2. 手机扫描桌面端二维码，确认账号与工作区，完成验证后，在 **Remote** 中找到对应主机。手机配对从桌面应用开始，不能用 CLI 或 IDE 扩展代替这一步。
3. 选择你自己的练习项目，发送下面的只读请求。先核对主机和目录，再允许修改。

```text
先不要修改文件、安装依赖或运行发布命令。
请确认当前项目，并列出顶层文件和已有的未提交改动。
如果你无法访问项目，说明失败发生在哪一步，不要改用其他目录。
```

成功标准是返回的项目和文件与桌面端一致。只看到主机名称，尚不能证明选对了项目。

## 用手机检查一次小任务

建议先继续[第一张学习卡片](./06-first-task.md)或已有任务，避免在小屏上批准大量陌生改动。发送：

```text
请汇报这次任务的改动文件、实际执行的检查、失败项和未完成事项。
如果涉及页面，说明是否已经打开并核验；如果涉及发布，分别说明
本地构建、提交推送、部署和线上正文的状态，并提供各自证据。
```

逐项检查回复。看到“构建成功”后仍需看页面；看到“已推送”后仍需看部署和线上内容。审批前确认操作对象与影响，不清楚就要求解释。

## 连不上时按阶段排查

| 阶段 | 下一步 |
| --- | --- |
| 手机没有 Remote | 更新两端应用，核对账号、工作区及功能开放状态 |
| 配对无法完成 | 检查桌面端连接设置，以及账号验证或管理员限制 |
| 曾连接，现在失联 | 检查主机电源、网络、休眠状态和应用是否运行 |
| 主机可见，项目不对 | 返回主机检查项目目录，再选择正确任务，不在错误目录继续操作 |

如果项目在 SSH 环境中，先从桌面应用连接该环境，手机仍通过桌面主机跟进。远程连接与其他执行位置的区别可回看[项目与运行位置](./05-app-overview.md)。

完成这章后，你应能说清楚：手机连接了哪台主机、任务实际使用哪个项目、目前验证到了哪一步。下一章进入[CLI 安装](./10-cli-installation.md)。
