# Codex 桌面安装与首次验证

::: tip 核对范围
官方资料最后核对日期：2026-09-26。本文依据官方安装与入门说明整理；本次没有重新安装客户端，也没有在 Windows 或 Linux 上执行安装测试。
:::

## 先找到当前官方入口

打开 [OpenAI 官方桌面应用说明](https://learn.chatgpt.com/docs/app)，使用页面上的下载入口。当前文档以 **ChatGPT 桌面应用**介绍安装流程，并在应用内提供 Codex 入口。旧教程中的产品名称、截图和按钮位置可能与当前版本不同。

- macOS、Windows：从官方页面选择适合自己系统的下载方式，按安装程序提示完成。兼容性要求以下载页当时的说明为准。
- Linux：从[官方快速开始](https://learn.chatgpt.com/docs/quickstart)进入其 Linux 安装指南，按发行版查看支持情况和安装步骤。

如果操作系统提示来源或签名异常，先核对下载来源和安装包，不把跳过系统提示当作通用安装步骤。安装失败时记录系统、应用版本和原始错误，再寻找对应处理方法。

## 登录并选择 Codex

按[官方快速开始](https://learn.chatgpt.com/docs/quickstart)完成下面几步：

1. 启动桌面应用，使用自己的 ChatGPT 账号登录。
2. 在产品选择菜单中选择 Codex。
3. 创建项目或打开一个供练习使用的文件夹，确认当前任务指向该目录。
4. 新建任务，写清你要的结果与允许的操作。

官方也列出 API Key 登录路径，但功能范围可能不同；第一次练习可先核对现有账号的访问能力。不要把订阅与 API 使用方式混为一谈，详见[账号与套餐核对](/start/03-account-plan)。

## 用一个只读任务检查是否准备好

把下面这段话发送给当前项目中的 Codex：

```text
请读取这个项目的 README，列出项目用途和启动前提。
说明你读了哪个文件；如果没有 README，就说明未找到。
仅阅读，不修改文件，不安装依赖，不执行启动命令。
```

按三层核验：应用能打开、账号能进入任务、任务能读取选定文件并给出可核查结果。仅看到界面正常加载，还不足以确认任务执行能力。

这段练习是本站建议的验收方法，不是本次维护已替你执行的安装测试。没有 README 时，如实报告缺失同样是有效结果。

## 卡住时先区分失败阶段

| 现象 | 下一步 |
| --- | --- |
| 下载或安装失败 | 回到官方入口，核对系统兼容性、文件来源和安装错误 |
| 无法登录 | 核对账号和组织要求，记录登录页错误，使用官方帮助入口或联系管理员 |
| 已登录但看不到 Codex 或所需功能 | 查看[官方套餐与功能范围](https://learn.chatgpt.com/docs/pricing)，再检查版本和工作区设置 |
| 能发任务但读不到文件 | 确认选定目录、文件是否存在，以及应用显示的权限请求 |

不要把换账号、升级套餐或切换地区当作所有错误的统一解法。反馈时提供脱敏后的错误文本即可，无需公开密码、验证码或密钥。
