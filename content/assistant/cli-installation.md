遇到 `install.sh 404`、安装脚本 404、`codex command not found` 或安装后版本没变化，先分清下载、本机命令、登录与实际任务四个阶段，再决定下一步。

1. **下载阶段**：记录安装方式、请求地址和脱敏错误。HTTP 404 与 DNS、TLS、连接中断是不同线索；不要把脚本 404 直接当作登录失败或项目权限问题，也不能凭一次报错断言官方安装服务整体不可用。
2. **本机命令阶段**：确认当前终端能否找到命令、实际找到的路径以及版本。`command not found` 先检查安装结果与 PATH；版本没变化先确认是否命中了另一个旧副本，不要连续混用多种安装方式、覆盖文件或删除配置。
3. **登录阶段**：命令已能运行后，再核对所选登录方式和状态。能显示版本不能证明已经登录，重新登录也不能解决尚未下载到安装脚本的问题。
4. **实际任务阶段**：登录状态与项目任务分开验收。进入练习项目做一次只读任务，并核对输出；任务失败时保留失败阶段和脱敏错误，不默认卸载重装。

可复制检查步骤、安装入口与验证范围见[安装 Codex CLI：排查脚本 404、找不到命令与登录失败](/start/10-cli-installation)。请补充操作系统、安装方式、实际命令及脱敏报错；不要附上密钥、认证缓存或原始私有日志。这份分流指引不代表已复现或修复你的安装故障。
