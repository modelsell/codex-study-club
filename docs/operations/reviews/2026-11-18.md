| 对照 | 实际观察 |
| --- | --- |
| 二参数 handler 返回 None | run 结束为 DeferredToolRequests，工具写入 0；不是继续等待 |
| 第三参数有默认值 token=None，返回 None | 没有收到 token，仍为 DeferredToolRequests、写入 0；与必选第三参数不同 |
| 必选第三参数返回 None，同进程解析批准 | 解析前 task 未完成、数据库 0 条；错误 token 和重复解析均 UserError；正确批准后回读 1 条本地报表 |
| token handler 等待超时 | 实际历史出现超时拒绝，工具写入 0；迟到解析 UserError，不把模型的最终文字当写入证据 |

| 保存待审历史后，在新进程提交批准 | 新 run 实际调用工具并回读 1 条；这是替代恢复流程，**不是恢复原 token 等待**，也未验证此路径的外部 exactly-once |
