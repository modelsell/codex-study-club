# 网站定位与信息架构

更新日期：2026-11-08。用户本轮明确要求重新思考定位、内容并改版；方案基于现有内容盘点及用户反馈，未用缺失的访问数据推导改版收益。

## 定位与选择

**Agent 实践室 · Codex Study Club**：给认真用 Agent 做事的中文读者，提供产品研究、工作方法与可复现实验。首页主张“看懂新工具，做出真成果”。保留 Codex Study Club 身份、教程与社区，增加能覆盖更多产品和非编程任务的中文编辑名称。

现有 33 篇案例混有方法指南、文件级工具、实际 CLI 与 SDK 实验；产品研究也沿用按日期排列的动态页。统一称“实战案例”会让读者难以识别证据层级；按品牌或更新时间浏览也不能直接回答下一步该读哪篇。选择按读者任务组织，并把已有文件产物集中到可追溯的工具包。保留日期档案帮助读者判断时效，不将它作为首页唯一主线。

不增加品牌配额或未经验证的产品推荐。新文章仍须通过需求、事实、深度与实际验证门槛；本轮整理既有合格内容，没有新增产品结论。研究目标覆盖工作交付、资料研究、浏览器操作和团队协作，条件不足的 T15 / T20 继续研究。

## 页面分工

| 页面 | 职责 |
| --- | --- |
| / | 一篇源码专题、四个任务起点、六篇深度选读、成果入口、更新笔记、资料助手与社区 |
| /paths | 首次交付、长任务续接、切换工具、团队交付四条阅读路线；连接问题、步骤、正文和读者成果 |
| /cases | 文章与实验；按真实核对日期排序，关键词、内容类型与原六类分类组合筛选；保留空状态与重置 |
| /cases#分类 | 保留原六个深链，与浏览器历史及筛选一致 |
| /cases/[slug] | 原文、日期与来源不变；选读文章增类型及实际验证范围，保留目录和继续阅读 |
| /community/updates | 五篇研究选读及原有日期档案；区分源码研究、SDK 与 CLI 实验 |

主题、互动练习、行业解读、赞助与社群保留在更多资源和页脚。手机菜单包含所有入口，不用隐藏内容来适配屏幕。

## 视觉与可访问性

- 纸色背景、深森林绿主视觉、浅绿重点，继续使用现有品牌三条标志；用文字、留白、线框和结构图建立阅读层级。
- 首页及文章列表去掉重复的通用封面，类型、问题、成果和范围优先；保留原文真实插图。
- 颜色由全局语义 token 维护，页面与组件使用 CSS Modules。正文保持阅读宽度，代码/表格自身滚动；容器允许窄屏，避免 body 最小宽度把内嵌浏览器裁切。
- 系统字体、现有图标，无新增 UI 依赖或外部字体请求；分享图与图标为本站静态资源。
- 保留键盘焦点、跳到正文、Escape 关闭菜单及焦点返回、减少动效支持、输入法候选确认保护。路线锚点留出顶部导航空间。
- 案例仅向客户端传递列表 metadata，正文留在服务端；筛选使用原生锚点保持 hashchange 与前进后退一致。

## 编辑索引与验证边界

`content/editorial/site.json` 集中维护定位、专题、选读、路线和工具包。`lib/editorial.ts` 从既有正文取日期和标题；索引校验器检查文档引用、类型、唯一标识、文件存在及原文链接，作为内容检查和构建的一部分。选读核对日期不更新原文产品核对日期。

全部原有 72 条 Sitemap URL 保留，新增 `/paths` 与 `/toolkit`，合计 74。没有批量修改文章日期、复制正文到 TSX，或把合成实验写成真实模型任务。下载不是学习完成，技术验收不是读者收益。

按 lint、生产构建、生成快照/编辑索引、既有回归、全站内部链接、实际文件保存及字节、桌面/窄屏交互验收。内嵌浏览器的预设尺寸须以页面实际报告尺寸为准，不仅凭设备参数宣称测试过某个手机。通过 `codex/` 分支与 PR 交付，推送、同 SHA Quality、Workers、正式页面分别核实；实际结果写入 [当日复盘](reviews/2026-11-08.md)。
